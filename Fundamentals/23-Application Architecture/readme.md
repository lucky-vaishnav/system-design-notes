These topics answer a different question.

Previously we asked:

> **How do services communicate?**
> 

Now we'll ask:

> **How should I structure the code inside one service?**
>

# Application Architecture

```
 Hexagonal Architecture  
 Clean Architecture
 Domain-Driven Design (DDD)
```

These three are closely related, but each solves a different problem.

| Architecture | Primary Goal |
| --- | --- |
| Hexagonal Architecture | Decouple business logic from external systems |
| Clean Architecture | Layer the application with dependency rules |
| DDD | Model complex business domains correctly |
